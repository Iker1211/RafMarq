# RafMarq

Landing page for RafMarq — Soluciones Eléctricas y Electrónicas (Cuenca, Ecuador).

Industrial design system built with boutique agency aesthetics: schematic circuit canvas, three-phase bus bar animations, editorial typography, custom cursor physics.

## Structure

```
├── images/
│   ├── favicon.png     # Site favicon
│   ├── logo-013.png    # Full emblem logo
│   ├── logo-014.png    # Monogram icon mark (512x512)
│   ├── logo-015.png    # Header wordmark
│   ├── work-1.png      # Field work: electrical panels
│   ├── work-2.png      # Field work: lighting & cabling
│   ├── work-3.png      # Field work: technical maintenance
│   └── work-4.png      # Field work: electronic circuits
├── index.html          # Landing page (self-contained, zero dependencies)
├── .gitignore
└── README.md
```

## Deploy

Static HTML. Drop `index.html` and `images/` on any web server, Netlify, Vercel, GitHub Pages, or Cloudflare Pages.
